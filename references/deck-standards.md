# Super AI Lab Run Deck Standards

## Information priority

1. Latest user correction in the current task.
2. Current confirmed agenda or role relay.
3. Current source screenshot, PDF, or PPTX.
4. Old deck content.
5. Standing defaults in this reference.

Never silently override a current correction with OCR or old-deck text.

## Standard visible sequence

Build only the sequence present in the current meeting. A common regular meeting may contain:

1. Cover: topic, Word of the Day, and compact meeting metadata.
2. Opening and rule introduction.
3. Standard rule cards when `include_standard_rules` is true.
4. Chairperson or theme speech when confirmed.
5. Toastmaster opening and officer declarations.
6. Guest introduction, group photo, or new-member welcome.
7. Prepared speeches.
8. Table Topics.
9. Break.
10. Evaluations and officer reports.
11. Awards, sharing, and closing.

Add, remove, and reorder sections according to actual meeting truth.

## Standard rule cards

The bundled generator can add these cards after a row with `kind: "rules"`:

- `3个提醒`: `手机调为震动或者静音模式`; `不要在会场来回走动`; `不要私下交谈`.
- `3个提倡`: `上台及发言结束，请与主持人握手交接`; `演讲精彩的、卡顿的，掌声鼓励`; `与主持人、演讲者多多互动`.
- `4个禁忌`: `政治`; `宗教`; `性`; `传销`; subtitle `请会议期间不要提及`.

## Content boundaries

- Keep host scripts, next-speaker reminders, and handoff notes off visible slides unless presenter notes are explicitly requested.
- Do not add membership fees, benefits, or recruitment conditions to a normal run deck.
- Do not invent speech titles, Pathways projects, people, or roles.
- Do not show unresolved placeholders in a final deck.
- Preserve dense source-designed pages as supplied local images when that is more accurate than rebuilding them.

## Timing

- Use the current declared window; `19:30-21:30` is common but not mandatory.
- Display `start - end（duration）`, for example `19:53 - 20:00（7分钟）`.
- Use agenda-provided duration first and keep the complete timeline continuous.
- Do not duplicate time in several visual blocks on the same slide.

## Identity and wording

- Use `Super AI Lab头马俱乐部` for new meetings; retain the confirmed historical name when working on a historical meeting or existing source.
- A common slogan is `明星闪耀，源来是你！`; use the current approved slogan when provided.
- Stable value words include `表达`, `AI`, `成长`, `温暖`, and `乐趣`.
- Use only the location confirmed in the current source. Do not carry a historical office address into a new meeting.
